# Crash Courses

Switching from another data tool? These crash courses will help you map what you already know to Sigilweaver's approach.

Each guide covers:
- **Terminology mapping** - What you called it there vs. what we call it here
- **Common tasks** - How to accomplish familiar operations
- **Key differences** - What works differently and why
- **First workflow** - A simple hands-on example to get started

## Choose Your Tool

| Tool | Best For | Guide |
|------|----------|-------|
| **Tableau Prep** | Business analysts familiar with Tableau's visual ETL | [Tableau Prep Guide](./tableau-prep) |
| **Alteryx** | Enterprise data analysts with complex workflow experience | [Alteryx Guide](./alteryx) |
| **Power Query** | Business users comfortable with M language (Excel/Power BI) | [Power Query Guide](./power-query) |
| **KNIME** | Scientists and researchers using node-based workflows | [KNIME Guide](./knime) |
| **Orange** | Data scientists building visual ML pipelines | [Orange Guide](./orange) |
| **Excel** | Spreadsheet users ready for scalable data pipelines | [Excel Users Guide](./excel) |

## Not Listed?

If you're coming from another tool (Pandas, dbt, Informatica, etc.), start with the [User Guide](../index) and explore the [Interface](../interface/canvas) documentation. The core concepts section covers everything you need to know.
