# Comparisons

Sigilweaver is often compared to other data tools. While we share many concepts with visual ETL platforms and checking dataframe libraries, our philosophy is distinct: **Visual design that compiles to code.**

A few things that set Sigilweaver apart:

- **Interactive development** - Partial previews and intermediate result caching mean you get instant feedback as you build, without waiting for full workflow re-runs.
- **Optimized production execution** - When running end-to-end, Sigilweaver leverages Polars' predicate pushdown, projection pushdown, and lazy evaluation to be as fast and memory-efficient as hand-written code.
- **Open source, no lock-in** - Your workflows are open JSON. Run them forever, even without us.
