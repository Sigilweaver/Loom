# Configuration Panel

The left pane shows the settings for whatever you have selected. With a tool selected it shows that tool's configuration. With nothing selected it shows the **Tools**, **Workflow**, **Settings** and **AI** tabs.

## Tool configuration

Select a tool on the canvas to configure it. The pane shows, from top to bottom:

1. **Header.** The tool's icon and name, a warning triangle if it is a blocking tool, its tool ID, and a link to this documentation.
2. **Comment.** A one-line note that also appears under the tool on the canvas. Loom generates it from the configuration. Click it to edit, and use the reset button to return to the generated text.
3. **Options.** The settings for this tool. See the [Tools Reference](../tools/index.md).

Changes apply immediately and there is no Save button in the pane. The tab shows an unsaved-changes dot until you save the workflow with `Ctrl+S`.

### Common controls

| Control                      | Where you see it                            |
| ---------------------------- | ------------------------------------------- |
| File path with **Browse**    | Read and Write tools                        |
| **Remote** file browser      | Read and Write tools in External and Hub modes. It browses files on the Server. |
| Column pickers               | Filter, Schema, Sort, Aggregate, Join, Pivot, Unpivot, Unique |
| Basic / Custom switch        | Filter and Calculate                        |
| Expression editor            | Custom mode. It offers autocomplete for column names and Polars methods. |

Column pickers fill in from the tool's input, so connect the input wire first. If the input is not connected or the upstream tool has an error, the pickers stay empty.

## Workflow tab

Click the **Workflow** tab with no tool selected to see:

- **Workflow Name**, **Description** and **Author**, saved in the `.swwf` file.
- The number of tools and wires.
- A live **code viewer** with two views:
  - **JSON** shows the workflow file as it will be saved.
  - **Python** shows standalone Polars code generated by the Server. Copy it and run it without Loom. Database credentials are replaced by placeholders.

Use the **Copy** button to copy either view. `Ctrl+Alt+X` jumps to this tab.

## Resizing

Drag the right edge of the pane to resize it. The width returns to its default when you restart Studio.
