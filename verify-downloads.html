Verify Your Downloads

Learn how to verify SHA256 checksums for Sigilweaver downloads — a best practice for ensuring file integrity.

Our Build & Release Process

Sigilweaver releases are built using a fully automated GitHub Actions pipeline in a clean, isolated environment. After successful builds, artifacts are securely uploaded to Backblaze B2 storage using credentials that only the project maintainer has access to.

This means our release process is reproducible and tamper-resistant. While verifying checksums is always good security practice, you can trust that our builds come from a secure, automated pipeline rather than someone's local machine.

Want to verify anyway?

Checksum verification is recommended for peace of mind and to ensure your download wasn't corrupted, but it's not strictly mandatory given our secure build process. If you'd like to verify your download, the instructions below will show you how for your platform.

How to Verify: Understanding SHA256 Checksums

A SHA256 checksum is a cryptographic hash that uniquely identifies a file. By comparing the checksum of your downloaded file with the one we provide, you can verify that:

  • The file downloaded completely without corruption
  • The file hasn't been tampered with or modified
  • You received the exact file we published

Windows

Using PowerShell (Built-in)

  1. Open PowerShell (Right-click Start → Windows PowerShell)
  2. Navigate to your Downloads folder: 
    cd ~/Downloads
  3. Run the checksum command: 
    Get-FileHash Sigilweaver-Setup.exe -Algorithm SHA256
  4. Compare the output with the SHA256 shown on the downloads page

Example output:

Algorithm       Hash
---------       ----
SHA256          56254CC60A4FEACFC9D44B69CD8956D9F328DBA684EC8E8194A5C502B340E557

macOS

Using Terminal (Built-in)

  1. Open Terminal (Applications → Utilities → Terminal)
  2. Navigate to your Downloads folder: 
    cd ~/Downloads
  3. Run the checksum command (replace with your downloaded filename): 
    shasum -a 256 Sigilweaver.dmg
  4. Compare the output with the SHA256 shown on the downloads page

Example output:

56254cc60a4feacfc9d44b69cd8956d9f328dba684ec8e8194a5c502b340e557  Sigilweaver.dmg

Linux

Using Terminal (Built-in)

  1. Open your terminal
  2. Navigate to your Downloads folder: 
    cd ~/Downloads
  3. Run the checksum command (replace with your downloaded filename): 
    sha256sum Sigilweaver.AppImage
  4. Compare the output with the SHA256 shown on the downloads page

Example output:

98ed19ce23d7cef7993fa7f8e5bb5550b46b1b083b0a32498eac3b2274d7a351  Sigilweaver-x64.AppImage

💡 Pro Tip: Automated verification

You can create a file with the expected checksum and verify automatically:

echo "EXPECTED_SHA256  Sigilweaver-x64.AppImage" | sha256sum -c

This will output "OK" if the checksum matches.

⚠️ What if the checksums don't match?

If the SHA256 checksum you calculated doesn't match the one on our downloads page, do not run the file. This could indicate:

  • The download was corrupted during transfer
  • The file has been tampered with
  • You downloaded a different version than expected

What to do:

  1. Delete the downloaded file
  2. Clear your browser cache
  3. Download the file again from sigilweaver.app/downloads
  4. Verify the checksum again
  5. If it still doesn't match, report it on GitHub Issues

Why Verify Downloads? (Best Practice)

While our automated build pipeline provides strong security guarantees, verifying checksums is a good security habit — especially if you're:

🌐

On Untrusted Networks

Public WiFi or networks where man-in-the-middle attacks are possible (though our HTTPS helps here too).

✓

Checking File Integrity

Confirm the file wasn't corrupted during download, which could cause installation errors or crashes.

📋

Meeting Compliance Requirements

Some organizations require checksum verification as part of their software deployment policies.

🛡️

Extra Peace of Mind

Trust, but verify — a cornerstone of good security practice.
