Privacy Policy

Last updated: January 1, 2026

1. Introduction

This Privacy Policy explains how Sigilweaver LLC ("we", "us", or "our") collects, uses, and protects information when you use the Sigilweaver website (sigilweaver.app) and software (collectively, the "Service").

We are committed to respecting your privacy. As an open source project, we believe in transparency about what data we collect and how we use it.

TL;DR Summary

  • No telemetry or analytics — the software doesn't phone home
  • Fully local processing — all data stays on your machine
  • No user accounts — no authentication or cloud sync
  • No crash reporting — errors are logged locally only
  • We don't sell your data — ever
  • Open source (AGPL-3.0) — verify our claims yourself

2. Information We Collect

2.1 Sigilweaver Desktop Application

The Sigilweaver software does not collect, transmit, or store personal data on any external servers. There is no telemetry, analytics, or crash reporting.

Data stored locally on your machine:

  • User Settings: Author name (defaults to system username), backend URL, theme preferences, and UI settings — stored via Electron in your system's standard app data location
  • Workflow Files (.swwf): Your pipeline configurations, tool settings, wire connections, and metadata — saved where you choose
  • Your Data Files: CSV, Parquet, and other files you work with remain in your specified locations

Architecture: The backend runs entirely on localhost (:8000). Once installed, no internet connection is required for the application to function.

2.2 Website (sigilweaver.app)

When you visit our website, the following information may be collected:

  • Server Logs: Standard web server logs including IP addresses, browser type, referring pages, and timestamps. These are used for security and troubleshooting purposes.
  • Contact Information: If you voluntarily contact us via email or GitHub, we receive the information you provide.

2.3 Information We Do NOT Collect

  • No analytics services (like Google Analytics, Mixpanel, or Amplitude)
  • No advertising or marketing trackers
  • No crash reporting services (like Sentry)
  • No user accounts or authentication
  • No cloud sync or remote storage of your data

3. Third-Party Services

3.1 Desktop Application

The desktop app loads icons from external CDNs when you open the Data Source Selector. This is the only network activity beyond the local backend:

Icon CDNs (Desktop App)

  • Simple Icons (cdn.simpleicons.org) — data source icons (CSV, PostgreSQL, etc.)
  • jsDelivr (cdn.jsdelivr.net) — Oracle database icon

These CDNs may log your IP address. See: Simple Icons Privacy, jsDelivr Privacy

3.2 Website (sigilweaver.app)

Our website uses the following third-party services:

Website Hosting & CDNs

  • Cloudflare Workers — website hosting and security (Privacy Policy)
  • Backblaze B2 + CDN — application downloads (Privacy Policy)
  • Tailwind CSS CDN (cdn.tailwindcss.com) — styling
  • Cloudflare CDN (cdnjs.cloudflare.com) — GSAP animations and Prism.js
  • Google Fonts (fonts.googleapis.com) — typography (Privacy Policy)

These services may log your IP address as part of their standard operations.

GitHub

Our source code is hosted on GitHub. If you interact with our repositories (issues, pull requests, discussions), GitHub's privacy policy applies.

4. Cookies

Our website does not set any first-party cookies for tracking or analytics purposes.

Third-party services we use (such as CDNs) may set their own cookies. These are typically functional cookies necessary for content delivery and do not track you for advertising purposes.
